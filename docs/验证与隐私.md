# 验证与隐私

发行前检查安装器、解包载荷以及加密界面资源的解密内容。检查同时覆盖 UTF-8 / ASCII 和 UTF-16，避免只扫描文本而漏掉 DLL 断言中的本机路径。

## 发布边界

- 不上传个人服务器地址、静态 TURN 凭据、私钥、证书、运行时配置、TS 身份、聊天记录、开发历史或测试驱动。
- 不上传完整开发工作区、构建资源密钥或内部隐私扫描规则。
- 保留上游组件许可证、公共文档地址和已签名微软依赖，不修改第三方签名文件。
- `ts3share.local` 是插件内部 WebView 虚拟源，不是公网服务器。
- 创作者 ID 与二维码由用户明确要求展示，属于安装器有意保留的图片内容。

## 测试范围

两版需要通过最终安装包的隔离安装、版本切换、载荷哈希和卸载检查。先前的功能回归覆盖了真实插件 DLL / WebView、资源完整性、音频版裁减、降噪模型、教程首次触发和完成状态保存。教程使用实际 Qt 桥 DLL 的隔离宿主验证。

Windows 构建号门槛允许 19044 及更新版本，并保留系统采音接口实际初始化结果检查。没有对不支持的环境自动改采全部系统声音。

## 尚未覆盖

- Windows 10 21H2 实机的麦克风试听和完整采音。
- 公网两台电脑的最终屏幕共享与长时间连麦。
- 每种显卡、DPI、企业策略、系统裁剪和播放器受保护内容。

静态审查及隔离测试不等于安全认证，也不能证明所有系统和网络环境均可正常采集。具体发行文件哈希见对应版本的 SHA256 校验文件。
