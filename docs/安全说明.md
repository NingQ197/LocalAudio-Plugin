# 屏幕共享与连接安全

## 谁可以观看

开始共享后，当前 TeamSpeak 频道的成员可以使用兼容客户端直接观看，无需逐人申请。需要限制观众时，请先使用频道密码或其他 TeamSpeak 频道访问控制。

连接使用 TeamSpeak 提供的成员身份与频道信息，并为每次观看建立独立会话。离开频道、身份变化或结束共享后，旧连接应停止使用。昵称不能代替成员身份。

兼容协议不等于客户端版本证明。开源代码可以被修改，LocalAudio 不提供“只允许未经修改的原版插件观看”的远程认证保证。

## 中继账户

TURN 用户名和密码控制中继服务器的使用权限，不决定谁能观看共享。

保存的中继凭据使用当前 Windows 用户的 DPAPI 保护，并绑定配置时的目标地址。自动地址变化后，不会继续向新目标附加旧凭据。升级旧配置后可能需要重新输入并保存一次；永久账户不需要定期续签。

需要在多个 TS 服务器上使用同一个中继时，请明确填写固定中继地址。

## 传输与本机边界

媒体通过 WebRTC 的 DTLS-SRTP 链路传输，TeamSpeak 承载协商信令。TURN 转发不会解除媒体加密；信令所依赖的 TS 服务器仍需可信。WebRTC 的安全模型见 [RFC 8827](https://www.rfc-editor.org/rfc/rfc8827.html)。

界面只加载随插件提供的资源，本机功能入口校验网页来源。资源散列和加密用于检查资源一致性，不能代替发布者代码签名，也不能抵御已获得同一 Windows 用户或 TS 进程权限的恶意程序。

请从本项目的 Release 页面下载；报告问题时，不要在公开 Issue 中附带密码、密钥或未经脱敏的个人配置。
