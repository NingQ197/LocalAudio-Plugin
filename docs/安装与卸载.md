# 安装与卸载

## 安装

先安装官方 TeamSpeak 3.6.2 64 位。LocalAudio 安装包只安装插件，不包含 TS 客户端。

完全退出 TS，运行音频版或屏幕版，确认客户端目录，再选择 TS 用户设置目录。标准安装通常保留默认值；以 `-localconfig` 启动的客户端使用其 `config` 子目录。

重启 TS 后，在附加组件中确认 LocalAudio 已启用。首次教程等待 TS 主窗口就绪；若还有首次许可或设置对话框，应先完成并关闭这些对话框。

## 两版互相切换

退出 TS，安装另一个版本。两版使用同一个插件位置，不应同时加载两份。屏幕版切换到音频版时，旧屏幕资源会移出活动插件目录，原文件留在备份中。

如果客户端的全局插件目录仍有旧一体包安装的 LocalAudio，应先卸载旧插件，避免与用户目录插件重复加载。

## 卸载和回退

在 Windows 已安装的应用中卸载 LocalAudio，或运行 TS 设置目录中的 `LocalAudio-Plugin/uninstall.exe`。

身份、书签、语音设置、`ts3-localaudio.ini`、`ts3-share-network.json`、`localaudio-guide.ini` 和历史备份会保留。音频版不创建屏幕共享网络配置。

回退前退出 TS，从 `LocalAudio-Plugin/backups` 找到需要的备份，将插件 DLL 和资源目录还原到 `plugins`。不要在 TS 正运行时替换 DLL。

## 常见问题

- **提示 TS 正在运行**：退出所选客户端及其托盘图标，再安装。安装器不会强制结束通话。
- **界面没有打开**：确认 TS 版本、插件启用状态和 WebView2 运行库；查看 TS 日志中的 LocalAudio 错误。
- **没有音乐**：先让目标应用播放声音，再扫描并选择。受保护内容、独占输出、系统策略或裁剪系统可能影响捕获。
- **屏幕能直连但中继失败**：由部署者核对 TURN 服务、账户和端口配置。安装包不包含可共用的个人中继账户。
- **卸载部分失败**：退出占用插件文件的程序后重试。受管文件未移除时，卸载入口会保留。
- **界面显示 2.5.0**：这是插件功能内核版本；安装器发行修订号为 2.5.2。
